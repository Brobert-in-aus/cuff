Connection

The headset's SSH identity:
Before the first install
The headset needs SSH turned on, once. On the Frame, switch to Desktop Mode and open Konsole, then:
  1. If you've never set a password: passwd
  2. Turn SSH on: sudo systemctl enable --now sshd
  3. Find its address: ip -4 addr show wlan0 (the number after inet)
The password is used once, to give this app its own key to the headset. It isn't saved.
